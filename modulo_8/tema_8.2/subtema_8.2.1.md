# Subtema 8.2.1: Claude Code (CLI) como Host MCP

Anthropic lanzó una herramienta CLI llamada **Claude Code** para desarrolladores que viven en la terminal.

## Integración MCP Nativa

Claude Code detecta automáticamente tus servidores MCP configurados en `claude_desktop_config.json`. ¡No necesitas configurar nada extra!

## Uso

1.  Asegúrate de tener tus servidores en el config de Claude Desktop.
2.  Ejecuta: `claude` en tu terminal.
3.  Pide: "Usa la herramienta X para..."

## Comandos Útiles

- `/mcp`: Lista los servidores conectados y su estado.
- `/doctor`: Diagnostica problemas de conexión con servidores MCP.

Es una forma excelente de probar tus herramientas en un flujo de trabajo real de codificación sin salir de la terminal.
