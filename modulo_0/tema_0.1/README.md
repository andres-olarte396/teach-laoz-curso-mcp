# Guía de Estudio: Tema 0.1

Esta es la guía de estudio para los subtemas de esta sección. Utiliza este índice para navegar por los conceptos clave.

## Subtemas

### [Subtema 0.1.1: JSON como Formato de Intercambio de Datos](./subtema_0.1.1.md)

> JSON (JavaScript Object Notation) es un formato ligero para el intercambio de datos. Es fácil de leer y escribir para los humanos, y fácil de analizar y generar para las máquinas. Es el estándar de facto para la comunicación entre clientes y servidores modernos, y es la base fundamental del protocolo MCP.

### [Subtema 0.1.2: HTTP: Métodos, Headers y Ciclo Request-Response](./subtema_0.1.2.md)

> HTTP (Hypertext Transfer Protocol) es la base de la comunicación de datos en la World Wide Web. Aunque MCP puede funcionar sobre otros transportes (como `stdio`), el transporte via HTTP (Server-Sent Events) es esencial para conectar con servidores remotos.

### [Subtema 0.1.3: APIs REST: Diseño y Consumo](./subtema_0.1.3.md)

> REST (Representational State Transfer) es un estilo arquitectónico para diseñar servicios web. Las APIs que siguen estos principios se llaman RESTful APIs. Utilizan HTTP y sus métodos (GET, POST, etc.) de manera semántica.
