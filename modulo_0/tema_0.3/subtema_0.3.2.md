# Subtema 0.3.2: IDEs y Extensiones Recomendadas

## VS Code

Visual Studio Code es el estándar de la industria.

### Extensiones Esenciales

- **Python:** Soporte oficial de Microsoft.
- **ESLint / Prettier:** Para mantener el código TypeScript limpio.
- **JSON Tools:** Para visualizar y formatear JSON fácilmente.

## Cursor / Windsurf

Estos son IDEs "AI-First", forks de VS Code con IA integrada profundamente.
Son **altamente recomendados** para este curso, ya que ellos mismos pueden actuar como **Hosts MCP**, permitiéndote conectar tus herramientas directamente a tu asistente de codificación.

- [Cursor](https://cursor.sh/)
- [Windsurf](https://codeium.com/windsurf)

## Claude Desktop

Aunque no es un IDE, es la aplicación de escritorio oficial de Anthropic que implementa el protocolo MCP como cliente (Host). La usaremos extensivamente para probar nuestros servidores.

- Descarga: [claude.ai/download](https://claude.ai/download) (Disponible para Mac y Windows).
