# Guía de Estudio: Tema 9.1

Esta es la guía de estudio para los subtemas de esta sección. Utiliza este índice para navegar por los conceptos clave.

## Subtemas

### [Subtema 9.1.1: Superficie de Ataque: Host, Client y Server](./subtema_9.1.1.md)

> MCP conecta sistemas locales con LLMs remotos y servicios externos. Esto crea una superficie de ataque única.

### [Subtema 9.1.2: Tool Poisoning y Exfiltración de Datos](./subtema_9.1.2.md)

> Un servidor malicioso no necesita "hackear" tu ordenador técnicamente; solo necesita engañar al LLM.

### [Subtema 9.1.3: Prompt Injection Indirecto](./subtema_9.1.3.md)

> Este es el ataque más sutil. El atacante no interactúa contigo, sino que deja una "trampa".

### [Subtema 9.1.4: DNS Rebinding y Session Hijacking](./subtema_9.1.4.md)

> Si ejecutas un servidor MCP localmente que escucha en HTTP (`localhost:8080`), eres vulnerable a ataques desde el navegador.
